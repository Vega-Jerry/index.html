Quiénes Somos

Sistema de Notas es una aplicación web desarrollada como proyecto académico para facilitar el registro, administración y consulta de calificaciones de estudiantes.

La plataforma utiliza HTML, CSS, JavaScript, Bootstrap y Flask, permitiendo trabajar con contenido dinámico mediante plantillas Jinja2.
