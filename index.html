Sistema de Notas

Plataforma web que facilita el registro de calificaciones por parte de docentes y la consulta inmediata de notas por estudiantes desde cualquier dispositivo.

Ir a Gestión

Quiénes Somos

Sistema de notas es un proyecto desarrollado con el objetivo de modernizar y digitalizar la gestión académica de calificaciones.

El sistema está diseñado para ser intuitivo tanto para docentes al momento de registrar notas, como para estudiantes al consultar su rendimiento académico.
